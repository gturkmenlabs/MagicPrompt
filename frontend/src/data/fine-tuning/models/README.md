# Fine-tuned model kayıtları

Her model sürümü için alt klasör açın:

```
models/<model_id>/model-card.json
```

Şablon: [`_template/model-card.json`](_template/model-card.json)  
JSON şeması: [`docs/model-card.schema.json`](../../../docs/model-card.schema.json)

Fine-tune job tamamlandıktan sonra değerlendirme metriklerini (`reports/quality-dashboard.json`, regression çıktıları) modele kartına işleyin.
